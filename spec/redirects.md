# Redirecciones

No se identificaron rutas públicas anteriores que requieran redirección al momento de configurar
el despliegue en `https://aguus1610.github.io/EAD-web/`.

Antes de renombrar una ruta publicada, registrar aquí la URL anterior, su destino y la fecha del
cambio. GitHub Pages no ofrece redirecciones de servidor, por lo que cada caso debe resolverse con
una página estática compatible o conservar la URL existente.
