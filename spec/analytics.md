# Política de medición

No se habilita analítica en el lanzamiento.

- No se cargan cookies, píxeles, grabadores de sesión ni SDK de terceros.
- El contenido del formulario no se usa para analítica. Sólo se transmite cuando el usuario elige enviarlo mediante Formspree o abrirlo en WhatsApp.
- No se registran clics a WhatsApp, teléfono o correo mientras no exista un objetivo medible, un
  proveedor aprobado y una revisión de consentimiento.
- Las fichas futuras podrán mostrar una portada local de Reel. El script de Instagram sólo se carga después de que el visitante elige reproducirlo y se le informa la conexión con el tercero.
- Si se aprueba medición futura, los eventos solo podrán identificar el tipo de conversión y la ruta
  pública; nunca nombres, teléfonos, correos, parámetros del mensaje ni texto ingresado.

La ausencia de analítica es deliberada y no afecta ningún recorrido comercial.
