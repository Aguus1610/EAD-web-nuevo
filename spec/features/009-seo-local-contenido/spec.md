# 009 · SEO local y contenido compartible

**Estado:** implementada

## Qué hace

Implementa títulos, descripciones, URLs canónicas, Open Graph, sitemap, robots, datos estructurados y enlaces internos para que buscadores y redes comprendan el negocio, sus servicios, ubicación, marcas y trabajos. Define además una base editorial para contenido local y consultas frecuentes sin crear páginas engañosas.

## Por qué

Una web publicitaria solo cumple su objetivo si puede descubrirse y compartirse correctamente. El SEO debe partir de contenido útil, datos consistentes y páginas específicas, no de repetir palabras clave ni crear ubicaciones donde el taller no presta servicio.

## Criterios de aceptación

- [ ] Cada página indexable tiene título, descripción, canonical e imagen social únicos o una herencia explícita adecuada.
- [ ] Se genera `sitemap.xml` con todas las rutas públicas aprobadas y `robots.txt` coherente con el entorno.
- [ ] Existe una página 404 útil con navegación y contacto.
- [ ] Los datos estructurados representan al negocio, la ubicación y los servicios sin afirmar información no confirmada.
- [ ] Nombre, dirección, teléfono y URL son consistentes en todo el sitio cuando están disponibles.
- [ ] Las páginas de servicio y proyecto enlazan contenido relacionado de forma natural.
- [ ] No existen páginas de localidad duplicadas, texto oculto, relleno de palabras clave ni contenido generado sin revisión.
- [ ] Los previews sociales muestran logo o imagen autorizada, título legible y descripción correcta.
- [ ] Las rutas antiguas o modificadas se documentan para redirección antes de publicar.
- [ ] El build detecta títulos ausentes, descripciones vacías y URLs canónicas inválidas.

## Fuera de alcance

- No se garantiza posición en buscadores ni volumen de clientes.
- No se compran enlaces, reseñas ni anuncios desde esta feature.
- No se crean fichas de Google Business Profile ni campañas publicitarias, aunque la web queda preparada para enlazarlas.
