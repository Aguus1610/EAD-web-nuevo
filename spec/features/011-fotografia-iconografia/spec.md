# 011 · Fotografía real e iconografía

**Estado:** implementada

## Qué hace

Reemplaza las ilustraciones técnicas grandes por fotografías reales autorizadas y amplía el registro visual del taller, equipos y componentes. Rediseña los iconos de servicios y productos para que cada símbolo explique la categoría que acompaña.

## Por qué

Las fotografías aportan evidencia concreta del trabajo y los iconos reconocibles reducen el esfuerzo necesario para distinguir servicios y líneas de consulta.

## Criterios de aceptación

- [x] Las páginas comerciales no muestran `CraneVisual` ni `TechnicalVisual`.
- [x] Los encabezados principales utilizan fotografías reales con texto alternativo y dimensiones declaradas.
- [x] El catálogo contiene entre 20 y 24 WebP seleccionados de los archivos autorizados.
- [x] Ninguna fotografía publicada expone rostros, patentes, documentos ni identificadores personales legibles.
- [x] Las fotografías no se presentan como proyectos específicos sin título, problema, intervención y resultado confirmados.
- [x] La galería de Empresa conserva seis imágenes rotativas por build.
- [x] Los cuatro servicios tienen iconos distintos y reconocibles.
- [x] Las cuatro categorías de productos tienen iconos distintos y coherentes con su contenido.
- [x] La página 404 utiliza un icono simple, no una ilustración técnica grande.
- [x] El diseño funciona sin desborde en móvil, tablet y escritorio.
- [x] Las imágenes fuera del primer viewport usan carga diferida y todas reservan su espacio.
- [x] El build respeta los presupuestos de JavaScript, CSS, WebP y peso total.

## Fuera de alcance

- No se publican fichas de proyectos hasta contar con datos y autorización específicos.
- No se crean fotografías sintéticas ni se incorporan imágenes de stock.
- No se alteran ni recolorean los logos oficiales de EAD, Hidro-Grubert o Palfinger.
