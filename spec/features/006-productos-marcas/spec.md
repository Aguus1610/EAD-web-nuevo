# 006 · Productos y marcas representadas

**Estado:** implementada

## Qué hace

Presenta las categorías de productos que EAD Oleohidráulica comercializa o gestiona bajo consulta, incluidos repuestos originales Hidro-Grubert y Palfinger, componentes e implementos hidráulicos. Explica además la relación comercial con ambas marcas utilizando sus logos originales y la redacción aprobada por el negocio.

## Por qué

Muchos clientes buscan primero un repuesto, componente o marca. Una página específica permite captar esas consultas, establecer confianza y aclarar que disponibilidad, compatibilidad, precio y entrega se confirman de forma personalizada.

## Criterios de aceptación

- [ ] Existe una página de productos con categorías comprensibles y CTA por categoría.
- [ ] Los repuestos originales Hidro-Grubert y Palfinger aparecen como categorías destacadas con logos originales.
- [ ] La redacción sobre representación oficial o relación comercial coincide exactamente con el texto aprobado antes de publicar.
- [ ] Cada categoría aclara que compatibilidad, disponibilidad, precio y plazo se confirman bajo consulta.
- [ ] No se muestra stock, precio, carrito, pago ni promesa de entrega.
- [ ] No se atribuyen productos, garantías o especificaciones a una marca sin documentación.
- [ ] Los logos conservan color, relación de aspecto, área de seguridad y legibilidad.
- [ ] El formulario o enlace de consulta puede incluir categoría, marca, modelo de equipo y datos del repuesto.
- [ ] La página enlaza servicios relacionados sin confundir venta de producto con ejecución de trabajo.
- [ ] La interfaz sigue siendo coherente con EAD y no adopta la identidad completa de una marca representada.

## Fuera de alcance

- No se implementa comercio electrónico, gestión de stock, filtros por SKU ni descarga masiva de catálogos.
- No se republican catálogos o fotografías de fabricantes sin autorización.
- No se garantiza compatibilidad a partir de una descripción incompleta del cliente.
