# 007 · Portfolio de trabajos reales

**Estado:** infraestructura implementada; bloqueada por proyectos reales autorizados

## Qué hace

Crea un archivo visual de trabajos realizados por EAD Oleohidráulica con tarjetas, filtros simples y fichas individuales. Cada proyecto explica el equipo o necesidad, el problema inicial, la intervención realizada y el resultado, acompañado únicamente por fotografías autorizadas.

## Por qué

Los trabajos reales son la principal evidencia de capacidad técnica. Un portfolio estructurado ayuda a potenciales clientes a reconocer casos similares, mejora la credibilidad y permite reutilizar cada proyecto en buscadores, redes y conversaciones comerciales.

## Criterios de aceptación

- [ ] Existe una página de trabajos con tarjetas ordenadas y filtros por categoría que funcionan sin perder accesibilidad.
- [ ] Cada proyecto tiene slug, título, categoría, resumen, intervención, resultado, imágenes, textos alternativos y autorización de publicación.
- [ ] Ningún proyecto se publica con datos personales, patentes, documentos o marcas de clientes no autorizados.
- [ ] Las fichas distinguen claramente hechos confirmados de descripciones comerciales.
- [ ] Las imágenes usan formatos y tamaños optimizados sin alterar su contenido.
- [ ] Las galerías pueden recorrerse con teclado y no dependen de gestos táctiles exclusivos.
- [ ] Si no hay proyectos suficientes para un filtro, la interfaz informa el estado sin mostrar tarjetas ficticias.
- [ ] Cada ficha enlaza los servicios relacionados y ofrece una consulta contextual.
- [ ] Los proyectos destacados pueden aparecer en portada sin duplicar contenido.
- [ ] Agregar un proyecto nuevo requiere crear contenido y assets, no modificar componentes.

## Fuera de alcance

- No se publican reseñas de clientes sin autorización y fuente verificable.
- No se incorporan comentarios, cuentas de usuario ni carga pública de proyectos.
- No se generan comparaciones técnicas o métricas de rendimiento no documentadas.
