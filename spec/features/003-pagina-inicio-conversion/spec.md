# 003 · Página de inicio orientada a conversión

**Estado:** implementada

## Qué hace

Construye una portada que explica en pocos segundos qué hace EAD Oleohidráulica, para quién trabaja y cuál es el siguiente paso. La página resume servicios, experiencia, marcas, trabajos recientes, ubicación y canales de contacto, con llamadas a la acción claras.

## Por qué

La mayor parte del tráfico llegará primero a la portada. Debe transmitir profesionalismo, especialización y evidencia real sin obligar al visitante a leer todo el sitio antes de consultar.

## Criterios de aceptación

- [x] El primer bloque contiene un `h1` específico, una propuesta de valor comprensible y CTA primaria y secundaria funcionales.
- [x] La portada identifica reparación, instalación, integración vehicular, productos y mantenimiento sin convertir el hero en una lista extensa.
- [x] Se muestran señales de confianza verificables, incluida la experiencia del taller solo si el dato está aprobado para publicación.
- [x] Existe una sección de servicios destacados que conduce a fichas completas.
- [x] Los logos de Hidro-Grubert y Palfinger se muestran con proporción, espacio y texto de relación comercial aprobado.
- [x] Existe una vista previa de trabajos reales; si no hay proyectos cargados, se muestra un estado editorial honesto y no tarjetas ficticias.
- [x] La ubicación y área de atención se comunican sin inventar cobertura geográfica.
- [x] Cada bloque principal ofrece un siguiente paso claro sin repetir botones de forma invasiva.
- [x] El contenido clave y las CTA permanecen visibles y legibles en 360 px sin depender de una imagen de fondo.
- [x] La página no contiene carruseles automáticos, video de reproducción automática ni métricas inventadas.

## Fuera de alcance

- Las fichas completas de empresa, servicios, productos y proyectos se implementan en sus features específicas.
- No se añaden testimonios hasta contar con reseñas verificadas y autorización.
- No se diseña una campaña temporal ni una landing independiente por servicio.
