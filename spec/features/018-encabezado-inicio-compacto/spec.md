# 018 — Encabezado de inicio compacto

**Estado:** implementada; verificación completa (28/10/2026)

## Qué hace

Reemplaza el título largo del hero de Inicio por una presentación de identidad más corta: logo del taller en tamaño grande, el nombre «EAD Oleohidráulica» como `h1` y, debajo en menor tamaño, «Enzo A. Deux». Se conservan el subtítulo de una línea y los dos botones de acción; se retira el listado de áreas principales para reducir el alto del encabezado.

## Por qué

El hero anterior ocupaba mucho alto por un título de dos renglones y una lista de áreas. EAD pidió un encabezado más compacto que presente la marca y el nombre del titular, manteniendo el fondo fotográfico inmersivo.

## Criterios de aceptación

- [x] El `h1` de Inicio es «EAD Oleohidráulica» y la página conserva exactamente un `h1`.
- [x] «Enzo A. Deux» aparece debajo del título, en tamaño menor.
- [x] El logo del taller se muestra más grande; el subtítulo y los CTA siguen presentes.
- [x] El encabezado es más bajo que el anterior en 360, 768, 1024, 1440 y 2560 px.
- [x] El fondo fotográfico y el contraste AA se mantienen; sin desbordes horizontales.

## Fuera de alcance

- No se modifican las páginas internas ni sus encabezados.
- No se cambian las fotos ni el tratamiento inmersivo de 016.
